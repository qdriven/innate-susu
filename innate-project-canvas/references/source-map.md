# 来源与所有权

| 数据 | 权威来源 | 当前提取方式 |
| --- | --- | --- |
| Sprint 顺序、名称、预估、声明状态 | `docs/sprints/README.md` | Markdown 表格 |
| 任务 ID、交付、验收、依赖、声明状态 | `docs/sprints/S*.md` | 任务标题和具名字段 |
| 完成证据 | 任务卡中的 `evidence/...` 路径 | 文件系统存在性和非空检查 |
| 当前模块和包名 | 各模块 `package.json` | 包清单 |
| 当前运行时模块边 | 各模块 `dependencies` | 内部包名匹配 |
| 目标模块和目标边 | 对应 plans/architecture 决策 | 显式、带来源的 JSON 输入 |
| 可执行与下一任务 | 依赖图 | 派生，不手工维护 |
| HTML、Canvas、审计报告 | 上述来源 | 全部为下游生成物 |

`docs/plans/innate-dogic-dsh/` 保留里程碑意图和设计决策。当前版本不会从自由文本计划自动推断任务或目标图，因此涉及这些文件的变化仍需由 Agent 核对。

修改字段所有权时，同时更新本表、提取器、校验和测试。不要在 HTML 或 Widget 中修补某个数字来绕过来源冲突。
