# 视觉契约

## Tabs 与可选 Sidebar

- `index.html` 默认使用顶部 Tabs 展示总览／任务／模块／审计；Sidebar 是可切换选项，经典长页已下线，不再生成。
- 两种导航必须消费同一份快照，禁止为了视觉效果另建任务数字或模块清单。
- 布局选择、Sidebar 折叠状态和任务草稿只保存在当前浏览器；窄屏使用可横向滚动的 Tabs 或 Sidebar 抽屉。
- 任务筛选、搜索、模块选择和本地草稿不回写权威文档或快照。

## 任务编辑与分块

- 标题是独立字段，其余全部内容在同一个 Markdown 正文中编辑，不把每个展示块拆成独立编辑器。
- `##` 二级标题是展示分块边界；编辑预览和保存后的任务详情使用同一套安全渲染规则。
- 工具栏参考 Orca Issue Composer 分组，按钮通过 `mousedown` 阻止默认失焦以保留 textarea 选区；预览时隐藏，窄屏自身横向滚动。
- 支持段落、标题、字符格式、三类列表、引用、代码与链接；链接只允许 HTTP(S)，Markdown 原始 HTML 不执行。
- 保存只产生带“本地草稿”标识的浏览器副本，并提供复制与恢复原始入口。

## Sprint 看板

- 按 Sprint 分组，任务卡展示 ID、标题、派生状态、依赖、验收、来源和证据。
- 摘要数字从快照派生，不在模板中另写。
- `下一项` 与 `可执行` 来自依赖图；`done` 仍显示审计错误，不用绿色掩盖缺失证据。
- 详细验收默认折叠，避免把看板变成长文档。

## 模块交互

- 当前态用实线，目标态用虚线和“目标 · 未实现”标签。
- 箭头表示模块依赖方向，不用视觉位置暗示未声明的生命周期。
- 总览优先按 app、plugin、package、service、site、tool、external 分组；宽图允许横向滚动。
- 大图需要交互或分组时复用同一快照，不创建第二份节点清单。

## 通用

- 跟随系统明暗模式，字阶保持紧凑（正文 14px，辅助文字最小 11px，初始参照 orca 字阶整体上调两轮），状态色不能是唯一信息载体。
- 所有来源文本和任务文本转义；HTML 不执行快照中的标记或脚本。
- 页面不依赖 CDN。修改布局后实际检查生成 HTML，包括窄屏、长标题和空审计状态。
